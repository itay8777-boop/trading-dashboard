# Strategy Dashboard

גרף מניות/ETF לפיתוח ובדיקת אסטרטגיות: **Dash** + **TradingView Lightweight Charts** + **IB TWS**.

## הפעלה

```bash
.venv/bin/python -m dashboard.app
```

ואז <http://127.0.0.1:8050>. דורש TWS או IB Gateway פתוח על `127.0.0.1:7497` עם
*Enable ActiveX and Socket Clients* מסומן.

## מבנה

| קובץ | אחריות |
|---|---|
| `data.py` | שאיבה מ-IB והמרה לפורמט הגרף. נשען על `ib_data.py` שבשורש הפרויקט (דפדוף בקריאות מרובות + קאש parquet). |
| `strategy.py` | אינדיקטורים, קומפילציית קוד המשתמש והרצת הבקטסט. לא יודע דבר על Dash. |
| `panels.py` | פאנל הביצועים — עוטף את בוני הטבלאות של `ui_components.py`. |
| `chart.py` | אפשרויות התצוגה והרכבת המטען לגרף. לא יודע דבר על Dash. |
| `app.py` | פריסת Dash והקולבקים — הדבק בין השלושה. |
| `assets/chart.js` | מנוע הציור בדפדפן (Lightweight Charts). |
| `assets/style.css` | ערכת הנושא הכהה. |

## איך מרחיבים

**אינדיקטור חדש** — פונקציה ב-`strategy.py` שמקבלת מערך ומחזירה מערך. היא נכנסת
אוטומטית ל-namespace של קוד המשתמש ואפשר לקרוא לה דרך `self.I(...)`.

```python
def wma(values, n):
    w = np.arange(1, int(n) + 1)
    return pd.Series(values).rolling(int(n)).apply(
        lambda x: (x * w).sum() / w.sum(), raw=True).to_numpy()
```

ואז ב-`_compile()` הוסף אותה למילון ה-namespace, ובקוד האסטרטגיה:
`self.ma = self.I(wma, self.data.Close, 20)`.

**טיים-פריים חדש** — הוסף ל-`ib_data.TIMEFRAMES` ול-`MAX_CHUNK_DURATION` (מגבלת
המשך לבקשה בודדת מול IB), ואז ל-`TIMEFRAME_ORDER` ו-`DEFAULT_DAYS` כאן.

## מה כדאי לדעת

- **3 שנות היסטוריה בכל טיים-פריים** (`DEFAULT_DAYS`). נבדק מול TWS ש-IB באמת
  מחזיק דאטה 3 שנים אחורה בכל גודל בר, כולל נרות דקה.
- **המחיר הוא מספר הקריאות, לא זמינות הנתונים.** IB מגביל כל בקשה לפי גודל הבר:

  | טיים-פריים | משך לבקשה | קריאות ל-3 שנים | שאיבה ראשונה |
  |---|---|---|---|
  | 1m | שבוע | ~157 | ארוכה מאוד (דקות רבות) |
  | 5m–1h | חודש | ~36 | עשרות שניות עד דקות |
  | 4h / 1d | שנה | 3 | שניות |
  | 1w | שנתיים | 2 | שניות |

  נמדד: `1 W` של נרות דקה חוזר ב-1.5 שניות, `2 W` לוקח 36 שניות, ו-`1 M` לא חוזר
  בכלל — לכן החלוקה לשבועות היא הדרך היחידה, ולא ניתן לקצר אותה.
- **הגנת pacing.** IB חוסם יותר מ-60 בקשות ב-10 דקות לאותו חוזה, ולכן `ib_data`
  עוצר להפוגה כל 50 קריאות. בלי זה שאיבה ארוכה הייתה מקבלת דאטה חלקי בלי אזהרה.
- **הכל נשמר בקאש parquet**, כך שהמחיר משולם פעם אחת לכל סימבול/טיים-פריים;
  שאיבה חוזרת מיידית.
- **הנרות נשמרים בזיכרון השרת** (`_FRAMES` ב-`app.py`) ולא ב-`dcc.Store`, כדי שלא
  ייסעו לדפדפן ובחזרה בכל הרצת בקטסט. ההנחה היא תהליך יחיד — מתאים לשימוש מקומי.
- **VWAP מתאפס בכל יום מסחר**, כפי שמקובל. VWAP מצטבר על פני שבועות מאבד את
  משמעותו כמחיר ממוצע של הסשן.
- **הבקטסט רץ על backtesting.py.** הבחירה מכוונת: היא מפיקה בדיוק את מערך
  הסטטיסטיקות ש-`ui_components.py` יודע להציג (Sharpe, Sortino, Buy & Hold,
  Max Drawdown), ולכן פאנל הביצועים כאן זהה לזה שבאפליקציה הקיימת — אותם בוני
  טבלאות, אותן מחלקות CSS, אותם מספרים.
- **גרסת Lightweight Charts מוצמדת** (4.2.3). `assets/chart.js` תומך גם ב-API של
  v5, כך ששדרוג לא ישבור את הגרף בשקט.
